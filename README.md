# userscripts

Tampermonkey userscripts. Click a raw link below to install. Tampermonkey then checks this repo for updates on its own.

- `ticktick-kanban-sidebar.user.js`: TickTick Kanban task detail as a resizable right sidebar.
- `xero-sender-switcher.user.js`: adds a "Send from" selector to Xero quote and invoice email dialogs. [Install](https://raw.githubusercontent.com/conmar5/userscripts/main/xero-sender-switcher.user.js)
- `xero-branding-guard.user.js`: stops Xero silently applying the first branding theme to new quotes and invoices, and blocks saving until a theme is chosen, unless the contact has a default. [Install](https://raw.githubusercontent.com/conmar5/userscripts/main/xero-branding-guard.user.js)
